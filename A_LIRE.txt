PLANNING COMMANDES — APPLICATION ANDROID
=======================================

Application indépendante : pas de compte Claude, fonctionne sans Internet.
Le planning est enregistré dans le téléphone.

GitHub (gratuit) sert uniquement à FABRIQUER le fichier d'installation (APK)
à partir de ce dossier. Rien à installer sur le PC.


1. CRÉER UN COMPTE GITHUB (une seule fois)
-----------------------------------------
   - Sur le PC, allez sur https://github.com/signup et créez un compte gratuit.


2. CRÉER UN DÉPÔT (une seule fois)
---------------------------------
   - En haut à droite : « + » puis « New repository ».
   - Repository name :  planning-commandes
   - Choisissez « Public » (le plus simple : l'APK se télécharge sans se
     connecter sur le téléphone ; ce dossier ne contient aucune donnée
     personnelle, votre planning reste dans le téléphone).
     « Private » marche aussi, mais il faudra se connecter à GitHub dans le
     navigateur du téléphone pour télécharger l'APK.
   - Ne cochez rien d'autre, puis « Create repository ».


3. DÉPOSER CE DOSSIER
---------------------
   - Sur la page du dépôt, cliquez sur le lien « uploading an existing file ».
   - Ouvrez le dossier « android-app » dans l'Explorateur Windows,
     sélectionnez TOUT son contenu (Ctrl+A) et faites-le glisser dans la
     page GitHub. (Glissez le CONTENU du dossier, pas le dossier lui-même.)
   - En bas, cliquez sur « Commit changes ».


4. AJOUTER LA « RECETTE » DE FABRICATION (une seule fois)
---------------------------------------------------------
   - Ouvrez le fichier « apk.yml » de ce dossier avec le Bloc-notes,
     Ctrl+A puis Ctrl+C pour tout copier.
   - Sur GitHub : « Add file » > « Create new file ».
   - Dans la case du nom, tapez exactement :
         .github/workflows/apk.yml
     (les « / » créent les dossiers automatiquement).
   - Collez le contenu (Ctrl+V) dans la grande zone, puis « Commit changes ».
   - GitHub fabrique alors l'APK (environ 5 minutes) : onglet « Actions »,
     « Fabriquer l'APK » tourne (rond jaune), puis coche verte = APK prêt.
   - Croix rouge : cliquez dessus et envoyez une capture de l'erreur à Claude.


5. INSTALLER SUR LE TÉLÉPHONE
-----------------------------
   - Sur le téléphone, ouvrez dans le navigateur :
         https://github.com/VOTRE-PSEUDO/planning-commandes/releases/latest
     (remplacez VOTRE-PSEUDO par votre nom d'utilisateur GitHub).
   - Touchez « PlanningCommandes.apk » : il se télécharge.
   - Ouvrez le fichier téléchargé. Android demande d'autoriser l'installation
     depuis cette source (Chrome, Fichiers…) : autorisez, puis « Installer ».
   - Si Play Protect avertit d'une « appli inconnue » : c'est normal pour une
     appli personnelle hors Play Store. « Plus de détails » > « Installer quand même ».
   - L'icône « Planning Commandes » apparaît avec les autres applis.


UTILISATION
-----------
   - Onglet Commandes > « Ajouter une commande » : choisissez les bulletins PDF.
   - Depuis un mail ou l'appli Fichiers : « Ouvrir avec » ou « Partager » un
     bulletin PDF vers Planning Commandes l'importe directement.
   - Bouton PDF : « Enregistrer le PDF » (vous choisissez où) ou « Imprimer »
     (imprimante Wi-Fi ou « Enregistrer au format PDF »).
   - Le PDF créé sur le téléphone contient les données du planning : le
     programme PC peut le rouvrir.
   - Réglages > Sauvegarde > « Enregistrer une copie (.json) » de temps en temps :
     désinstaller l'application efface le planning.


METTRE À JOUR L'APPLICATION
---------------------------
   - Redéposez les fichiers modifiés sur GitHub (même méthode qu'à l'étape 3,
     « Add file » > « Upload files ») puis « Commit changes ».
   - Une nouvelle version se fabrique toute seule ; installez-la par-dessus
     l'ancienne depuis la même adresse : le planning est conservé
     (la clé de signature planning.keystore ne change pas — ne la supprimez pas).
