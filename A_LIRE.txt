PLANNING COMMANDES — GITHUB (APPLI ANDROID + PROGRAMME PC)
===========================================================

GitHub (gratuit) fabrique automatiquement :
  - PlanningCommandes.apk : l'application Android (indépendante ; Internet sert
    seulement à chercher une nouvelle version),
  - PlanningPDF.exe       : le programme PC pour Windows.
Tout le contenu du dépôt est dans « depot-github.zip » (dossier PlanningPDF).


1. PREMIÈRE FOIS : COMPTE ET DÉPÔT
----------------------------------
   - Créez un compte gratuit sur https://github.com/signup
   - « + » en haut à droite > « New repository », nom : planning-commandes,
     « Public », puis « Create repository ».


2. DÉPOSER LES FICHIERS (première fois ET à chaque mise à jour)
---------------------------------------------------------------
   - Clic droit sur « depot-github.zip » > « Extraire tout… » > « Extraire ».
   - Ouvrez le dossier « planning-commandes » obtenu.
   - Sur la page du dépôt : « Add file » > « Upload files »
     (première fois : lien « uploading an existing file »).
   - Sélectionnez tout le contenu du dossier (Ctrl+A) et glissez-le dans la page.
     Les fichiers déjà présents sont remplacés.
   - « Commit changes ».


3. LA RECETTE DE FABRICATION (une fois, puis quand Claude le demande)
---------------------------------------------------------------------
   GitHub ignore le dossier « .github » au glisser-déposer : la recette se colle
   à la main.
   - Ouvrez « apk.yml » (dans le dossier extrait) avec le Bloc-notes,
     Ctrl+A puis Ctrl+C.
   - Si le fichier n'existe pas encore sur GitHub :
       « Add file » > « Create new file », nom exact :  .github/workflows/apk.yml
   - S'il existe déjà : ouvrez .github > workflows > apk.yml, cliquez sur le
     crayon (Edit), Ctrl+A puis Ctrl+V pour remplacer tout le texte.
   - « Commit changes ».
   - Onglet « Actions » : « Fabriquer l'APK et l'exe » tourne (environ 5 à 10
     minutes). Coche verte = c'est prêt. Croix rouge : envoyez une capture à Claude.


4. INSTALLER SUR LE TÉLÉPHONE
-----------------------------
   - Sur le téléphone : https://github.com/VOTRE-PSEUDO/planning-commandes/releases/latest
   - Touchez « PlanningCommandes.apk », ouvrez le fichier téléchargé, autorisez
     l'installation depuis cette source, puis « Installer ».
   - Play Protect « appli inconnue » : « Plus de détails » > « Installer quand même ».
   - Mise à jour : AUTOMATIQUE à partir de cette version. Une fois par jour,
     l'application regarde la page Releases ; s'il y a mieux, un bandeau propose
     « Installer » (téléchargement + installation, Android demande de confirmer ;
     la 1re fois : autoriser « Planning Commandes » à installer des applications).
     Le planning est conservé. Sinon : même adresse, installez par-dessus.
   - Widgets : appui long sur l'écran d'accueil > « Widgets » >
     « Planning Commandes » > faites glisser :
       « Planning »          réglé à la pose : style (d'origine / GrapheneOS),
                             horaires (auto / toujours / jamais), 7 ou 14 jours
       « Prochain service »  mini-widget : le service en cours ou le prochain
     Appui long sur un widget posé > « Réglages » pour le modifier.
     Les anciens widgets déjà posés continuent de marcher.


5. RÉCUPÉRER LE PROGRAMME PC
----------------------------
   - Sur le PC : https://github.com/VOTRE-PSEUDO/planning-commandes/releases/tag/exe
   - Téléchargez « PlanningPDF.exe » et remplacez l'ancien dans le dossier
     PlanningPDF (à côté de codes.txt et du dossier commande).
   - Plus besoin de lancer « Creer l'exe (Windows).bat » (il marche toujours).
   - Mise à jour : AUTOMATIQUE pour l'exe téléchargé ici. Une fois par jour, il
     regarde la page Releases ; s'il y a mieux, il propose de la télécharger,
     se remplace à la fermeture et se relance (aussi : Aide > Rechercher une
     mise à jour…). Un exe fabriqué avec « Creer l'exe » ne se met pas à jour
     tout seul : téléchargez une fois celui de GitHub.
   - Windows peut avertir « Windows a protégé votre ordinateur » :
     « Informations complémentaires » > « Exécuter quand même ».


À SAVOIR
--------
   - Désinstaller l'application Android efface son planning : Réglages >
     « Enregistrer une copie / envoyer vers le PC » de temps en temps
     (l'appli le rappelle tous les 30 jours).
   - Ne supprimez jamais app/planning.keystore (clé de signature) : sans elle,
     les mises à jour ne s'installent plus par-dessus l'ancienne version.
