NOTICE — RÉGLER LES CODES DU PLANNING (fichier codes.txt)
=========================================================

Les codes se règlent dans le fichier « codes.txt », à côté du programme
(ou de PlanningPDF.exe). Inutile de toucher au code du programme ou de
refaire l'exe après une modification.


CONTENU ACTUEL
--------------

  # CODE     ; NOM     ; COULEUR  ; gros
  VAL002     ; S-VAL   ; bleu
  VAL001     ; M-VAL   ; vert
  ZBELLE     ; DISPO   ; violet
  RP         ; RP      ; orange   ; gros
  BLR303T    ; [date]  ;
  BLRRTM     ; [date]  ;
  BLR302T    ; [date] Montclair ;

Chaque ligne a 4 colonnes séparées par des ;

  1. CODE          : le code tel qu'il est écrit dans la colonne
                     « Utilisation » du bulletin de commande.
  2. NOM           : ce qui s'affiche dans le planning.
                     Remettez le même code pour ne pas le renommer.
                     Écrivez [date] pour afficher l'intitulé écrit sous
                     la date dans le bulletin (voir « Cas du [date] »).
  3. COULEUR       : la couleur de fond de la case (voir plus bas).
                     Laissez vide pour ne pas colorer la case.
  4. gros          : facultatif. Écrivez « gros » pour afficher le nom en
                     très gros au centre de la case (comme RP).
                     Sans « gros », le nom s'affiche juste après le
                     chiffre du jour (comme S-VAL).

Les lignes qui commencent par # sont des commentaires : elles sont ignorées.


AJOUTER UN CODE
---------------

Ajoutez simplement une ligne à la fin, par exemple :

  CA         ; CONGÉ   ; jaune    ; gros

Couleurs disponibles :
  bleu, vert, violet, orange, jaune, rose, rouge, turquoise,
  gris, beige, marron, blanc

Couleurs foncées (le texte de la case s'écrit alors en blanc) :
  noir, gris foncé, bleu foncé, vert foncé, rouge foncé

Ou une couleur précise :
  - trois nombres rouge,vert,bleu de 0 à 255   ex. 255,240,200
  - un code hexadécimal                         ex. #FFF0C8
  (Pour une couleur pastel, gardez des nombres entre 180 et 255.)


CAS DU [date] (ex. BLR303T)
---------------------------

Certains bulletins portent un intitulé sous la date, dans la colonne
« Date » :

    Mer 26/08/2026          Lun 14/09/2026
    GRAISS. ST-AUB/ROCH      GRAISSAGE MONTCLAIR

Avec la ligne   BLR303T ; [date] ;   c'est cet intitulé qui s'affiche
à côté du chiffre du jour (« 26 GRAISS. ST-AUB/ROCH »,
« 14 GRAISSAGE MONTCLAIR ») au lieu de « BLR303T ».
Vous pouvez utiliser [date] pour n'importe quel autre code, et lui
donner une couleur, ex. :   BLR303T ; [date] ; turquoise

On peut aussi ajouter du texte autour de [date], ex. :
    BLR302T    ; [date] Montclair ;
  -> « 31 NUCLEAIRE Montclair » (intitulé sous la date + « Montclair »).

Important : l'intitulé est lu au moment où le bulletin est ouvert.
Pour les jours déjà enregistrés avant cette version, rouvrez le
bulletin concerné.


NUITS : « DN » AUTOMATIQUE
--------------------------

Un service est une nuit quand sa fin de service (FS) tombe après minuit
(ex. PS 22:25 -> FS 04:45). Le lendemain de la DERNIÈRE nuit d'une
série, le planning affiche automatiquement « DN ».
Rien à saisir. Pour lui donner une couleur ou l'écrire en gros, ajoutez
une ligne dans codes.txt, ex. :
    DN         ; DN      ; gris
    DN         ; DN      ; gris     ; gros


MODIFIER LES CODES
------------------

  1. Dans le programme, cliquez sur le bouton « Codes… » :
     le fichier s'ouvre dans le Bloc-notes.
  2. Modifiez, puis enregistrez (Ctrl+S).
  3. Revenez dans la fenêtre du programme : le planning se met à jour
     tout de suite.
  4. Cliquez sur « Mettre à jour le PDF » pour reporter les changements
     dans le PDF de sortie.

Une ligne mal écrite (couleur inconnue, code manquant…) est signalée par
un message et ignorée ; le reste continue de fonctionner.

Un changement de nom ou de couleur s'applique aussi aux jours déjà
enregistrés, pas seulement aux prochains bulletins.

Couleur fixe : les repos, congés et fêtes ont TOUJOURS un fond orange,
quelle que soit la couleur écrite dans codes.txt, et même s'ils n'y
figurent pas : C, AH, RP, RPP, F, F0 à F9, FV, RU, RQ, RN, RM, CA, CET,
JF, VT, RS. Dans l'éditeur, leur palette est grisée. On peut toujours
changer leur nom et l'option « gros ». (Liste dans regles.json, « fond_bloque ».)


À SAVOIR
--------

  • Gardez « codes.txt » dans le même dossier que « PlanningPDF.exe ».
    Si vous déplacez l'exe, déplacez codes.txt avec lui.
  • Si codes.txt est supprimé, il est recréé automatiquement avec les
    réglages d'origine (S-VAL, M-VAL, DISPO, RP).
  • Le fichier peut être enregistré en UTF-8 ou en ANSI : les deux
    fonctionnent.
